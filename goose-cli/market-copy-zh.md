# Goose（商场文案）

短：Goose 终端 AI 智能体（Linux arm64 musl）。上游 v1.57.0 静态二进制重打包。gork.bot协助开发。

长：Goose（Block/aaif-goose）是开源 AI agent CLI，可在终端完成开发辅助与工具调用。本包为官方 Linux aarch64 musl 发行物 v1.57.0 的 KEMI 重打包（静态二进制未改），适用于 Ubuntu 20.04 aarch64（KEMI 101）。无需 Docker。需用户自备 LLM Provider Key。合主线：gork.bot协助开发。安装后提供 `/usr/bin/goose`。
