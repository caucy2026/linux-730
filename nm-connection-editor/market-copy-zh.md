Release 1.8.24-1ubuntu2。Ubuntu 20.04 没有独立的 nm-connection-editor 二进制软件包；该编辑器由 network-manager-gnome（源码包 network-manager-applet）一并提供，同包还包含 /usr/bin/nm-applet。捆绑官方同源精确版本硬依赖 libnma0 (= 1.8.24-1ubuntu3)。libnma0 自身没有再需捆绑的同源精确版本依赖。官方同源 gir1.2-nma-1.0 与 libnma-dev 已检查，不打包。官方 /usr/bin/nm-connection-editor 与 /usr/bin/nm-applet 均为 aarch64 ELF，留在官方路径；捆绑的 /usr/lib/aarch64-linux-gnu/libnma.so.0 同留官方路径。/opt/network-manager-gnome 下仅为符号链接。另有 /usr/bin/kemi-network-manager-gnome → nm-connection-editor。不同源依赖保持为 Depends。官方 Recommends（gnome-shell | notification-daemon、gnome-keyring、mobile-broadband-provider-info、iso-codes）保持为 Recommends。官方 Suggests（network-manager-openconnect-gnome 等 VPN 前端）保持为 Suggests。探针：3 个独立包装 aarch64 ELF，requiredGlibc 2.17（3 个有版本、0 个空值），无 GLIBCXX（0 个有版本、3 个空值，不把空值当作最大值），符合 Ubuntu 20.04 / KEMI 101（glibc ≤2.31）。官方软件包不带 .mo（Ubuntu language-pack 拆分），不发明语言包。官方编辑器桌面 Icon 为主题名 preferences-system-network；官方托盘/状态 PNG 与 SVG（80 PNG + 2 SVG）留在官方路径并只打包一次，不用作商城图标。从官方 Ubuntu 20.04 humanity-icon-theme 0.6.15 的 categories/64/preferences-system-network.svg 栅格化的 128×128 evidence PNG 仅用作商城 CREATE --icon，不打入 deb；不捆绑主题包。官方桌面 Name=Advanced Network Configuration 保留。商城 app_name=Advanced Network Configuration（官方桌面 Name，即该 GUI 的日常用户可见标题）。官方 appdata <name> 为 NetworkManager（项目/服务名），不用作商城 app_name。官方无 GenericName。官方相对 Exec
