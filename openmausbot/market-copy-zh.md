# OpenMausBot 商场文案

- 短描述：OpenMausBot headless 多引擎 Agent 服务（非 Electron 壳）
- 长描述：OpenMausBot 0.1.142 的 KEMI Linux arm64 headless 服务包。官方无 Linux aarch64 Electron；本包装 npm 包 + /usr/bin/openmausbot，复用 /opt/openclaw-node（Node≥24）。serve 后可用浏览器打开本机 UI。需用户自备引擎/密钥。gork.bot协助开发。
- 发布说明：首发商场 headless 服务包 0.1.142-1kemi1（version_code 10142）。边界：非桌面 Electron 壳。
