# Nemo

短描述：官方 Ubuntu 20.04 Nemo（Cinnamon 文件管理器）（focal-updates universe，arm64）

长描述：Nemo（官方软件包名与启动器均为 nemo）4.4.2-2ubuntu2，官方 Ubuntu 20.04（focal-updates universe）Architecture: arm64 软件包的 KEMI 重打包，新于 focal Release 4.4.2-2。官方 GUI stanza 无 Source 字段，未默认填充；同源兄弟包 stanza 明确列出 Source: nemo。已捆绑官方同源精确版本硬依赖 nemo-data (= 4.4.2-2ubuntu2，Architecture: all，76168 B，sha256 90176df6dd78211183a84250eb1582a71e643284ce5bbdfa1acea75e8a68a539) 与 libnemo-extension1 (= 4.4.2-2ubuntu2，arm64，38928 B，sha256 5dac6c49b91a4f3cdac0cbe90464e3a9b09547d701120294c1d5103bd0796838)。这两个捆绑包自身再无同源精确版本硬依赖。官方同源 gir1.2-nemo-3.0 与 libnemo-extension-dev 已检查，不打包（gir / -dev）。官方不同源 Depends 保持为 Depends。官方 Recommends（cinnamon-l10n (>= 4.4)、gvfs-backends、gvfs-fuse、librsvg2-common、nemo-fileroller (>= 4.4)）保持为 Recommends；nemo-fileroller 为 Recommends 而非精确版本硬依赖，其官方 stanza Source 字段缺失且未默认填充。官方 Suggests（eog、evince | pdf-viewer、totem | mp3-decoder、xdg-user-dirs）保持为 Suggests。官方 /usr/bin/nemo 等为 aarch64 ELF，留在官方路径。/opt/nemo 下仅为符号链接。另有 /usr/bin/kemi-nemo → nemo。探针：8 个独立包装 aarch64 ELF，requiredGlibc 2.17（8 个有版本、0 个空值），无 GLIBCXX（0 个有版本、8 个空值，不把空值当作最大值），符合 Ubuntu 20.04 / KEMI 101（glibc ≤2.31）。官方软件包不带 .mo，不发明语言包。官方应用图标为 16–32 hicolor apps/nemo.png 及可缩放 apps/nemo.svg（无官方 256），另有官方 action/status/emblem 图标与 pixmaps/nemo.xpm，共 47 个官方图标文件，均在官方路径只打包一次。从官方 apps/nemo.svg 栅格化的 128×128 evidence PNG 仅用作商城 CREATE --icon，不打入 deb。官方 action/status/emblem 图标不用作商城图标。官方主桌面 Name=Files 保留在桌面文件中。本包无 appdata <name>，无 GenericName。商城 app_name=Nemo（Files 过宽，类似 Printers 之于 Print Settings；官方自启动桌面 Name 即为 Nemo，此为该 Cinnamon 文件管理器的日常有辨识度标题）。官方相对 Exec 已改为绝对路径并添加缺失的 TryExec。官方辅助桌面 NoDisplay=true 保留；主桌面未发明 NoDisplay。官方 D-Bus Exec 已是绝对路径并保留。官方 GUI changelog 为指向已捆绑 libnemo-extension1 的悬空符号链接，捆绑后可解析，已保留官方符号链接，并用 cp -L 将真实官方 changelog 复制到 kemi 文档目录。官方 nemo-data 的 dh_python3 钩子已保留并改指向 kemi-nemo。已追加 glib-compile-schemas、desktop-database、icon-cache 与 ldconfig 钩子。本包提供版本化 Provides: nemo / nemo-data / libnemo-extension1 (= 4.4.2-2ubuntu2)。官方 SHA 与大小已与 ports.ubuntu.com 及 Aliyun ubuntu-ports（https）池文件及 focal-updates universe Packages stanza 核对一致。本轮无 librarian URL，ports 池目录无 .buildinfo。无 Debian 纪元，无波浪号。mall version_name 4.4.2-2ubuntu2kemi1 长度为 19，已被商城接受，无需缩短。与已上架的 Nautilus、Thunar、PCManFM 为不同应用。
