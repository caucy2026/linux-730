# Meld

短描述：Meld 图形化文件与目录对比合并工具（GTK3）

长描述：Meld 3.22.3 — 图形化文件、目录与版本库对比合并工具（Python + GTK3）。官方 Ubuntu/Debian all.deb 重打包；无原生 ELF，适配 Ubuntu 20.04 / KEMI 101。布局 /opt/meld + /usr/bin/meld。运行时依赖系统 python3（≥3.6，focal 为 3.8）、python3-gi、gir1.2-gtk-3.0、gir1.2-gtksource-4 与 patch。Meld 3.24.1 使用了 Python 3.9 类型写法，未采用。

发布说明：首发 KEMI Linux：官方 meld_3.22.3-2_all.deb 重打包为 kemi-meld；探针 0 ELF，依赖均可在 Ubuntu 20.04 安装。合主线：gork.bot协助开发
