# Foliate

短描述：Foliate 简洁现代的 GTK 电子书阅读器（GTK3）

长描述：Foliate 2.6.4 — 简洁现代的 GTK 电子书查看器（GJS + Epub.js）。官方 GTK3 all.deb 重打包；无原生 ELF，适配 Ubuntu 20.04 / KEMI 101。布局 /opt/foliate + /usr/bin/foliate。运行时依赖系统 gjs（≥1.52）、gir1.2-webkit2-4.0（WebKitGTK 4.0）与 python3。Foliate 3.x 需要 GTK4 / WebKitGTK 6，未采用。

发布说明：首发 KEMI Linux：官方 com.github.johnfactotum.foliate_2.6.4_all.deb（最后一条 GTK3 线）重打包为 kemi-foliate；探针 0 ELF，依赖均可在 Ubuntu 20.04 安装。合主线：gork.bot协助开发
