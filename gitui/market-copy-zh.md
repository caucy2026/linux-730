# gitui

**短描述**：gitui：极速终端 Git UI（arm64，GLIBC≤2.28）

**长描述**：gitui 0.28.1 — 用 Rust 编写的极速终端 Git 界面。官方 linux-aarch64 二进制（MAX GLIBC 2.28 ≤ 2.31），适配 KEMI Linux aarch64。安装后提供 `/usr/bin/gitui`。合主线：gork.bot协助开发。

**发行说明**：0.28.1-1kemi1 首发上架。上游 gitui-org/gitui v0.28.1 linux-aarch64（gnu MAX GLIBC 2.28；无 musl 资产）。gork.bot协助开发。
