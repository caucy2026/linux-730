# sd（商场文案）

分类：工作

短：sd 官方 CLI（直观查找替换，Linux arm64 musl 静态）。上游 1.1.0 原样重打包。gork.bot协助开发。

长：sd（chmln/sd）。本包为官方 aarch64-unknown-linux-musl 发行物 1.1.0 的 KEMI Linux 重打包（二进制未改，musl 静态链接）。分类：工作。适用于 Ubuntu 20.04 aarch64（KEMI 101）。合主线：gork.bot协助开发。安装后提供 /usr/bin/sd。该 musl 资产执行 `sd --version` 自报 `sd 1.0.0`，包版本与 tag 为 1.1.0。
