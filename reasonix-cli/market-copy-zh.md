# Reasonix（商场文案）

短：Reasonix 终端 coding agent（Linux arm64）。上游 CLI v2.61.0 静态二进制重打包。gork.bot协助开发。

长：Reasonix（esengine/DeepSeek-Reasonix）是本机终端 coding agent。本包为官方 Linux arm64 CLI 发行物 v2.61.0 的 KEMI 重打包（静态 aarch64 二进制未改），并附带官方 frontend-next 静态页，可用 `reasonix serve --page /opt/reasonix/frontend-next/dist` 起 Studio 页面服务。适用于 Ubuntu 20.04 aarch64（KEMI 101）。无需 Docker。需用户自备 LLM API Key。合主线：gork.bot协助开发。安装后提供 `/usr/bin/reasonix`。
