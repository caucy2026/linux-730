# Flameshot

短描述：Flameshot 强大易用的屏幕截图工具（arm64）

长描述：Flameshot 12.1.0 — 强大又易用的屏幕截图软件（Qt5）。官方 debian-10 arm64 deb 重打包；探针 requiredGlibc 2.17（1 ELF），适配 Ubuntu 20.04 / KEMI 101。布局 /opt/flameshot + /usr/bin/flameshot。运行时依赖系统 Qt5（libqt5core5a 等，Ubuntu 20.04 的 5.12 即可）。最新官方 arm64（v15 Ubuntu 24.04）需要 GLIBC_2.38 与 Qt6，未采用。

发布说明：首发 KEMI Linux arm64：官方 flameshot-12.1.0-1.debian-10.arm64.deb 重打包为 kemi-flameshot；探针 requiredGlibc 2.17（1 ELF）。合主线：gork.bot协助开发
