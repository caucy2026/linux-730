# Codewhale（商场文案）

短：Codewhale 终端 coding agent（Linux arm64）。上游 CLI/TUI v0.10.4 静态二进制重打包。gork.bot协助开发。

长：Codewhale（codewhale-hq/Codewhale）是本机终端 CLI/TUI coding agent。本包为官方 Linux arm64 发行物 v0.10.4 的 KEMI 重打包（静态 aarch64 二进制未改；官方 `codew` 为同一二进制的别名）。适用于 Ubuntu 20.04 aarch64（KEMI 101）。需用户自备 API Key。合主线：gork.bot协助开发。安装后提供 `/usr/bin/codewhale` 与 `/usr/bin/codew`。
