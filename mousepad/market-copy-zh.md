# Mousepad

短描述：Mousepad 轻量 Xfce GTK3 文本编辑器（arm64）

长描述：Mousepad 0.4.2 — 面向 Xfce 的轻量 GTK3 纯文本编辑器。官方 Ubuntu 20.04（focal）arm64 deb 重打包；探针 requiredGlibc 2.17（1 ELF），适配 Ubuntu 20.04 / KEMI 101。布局 /opt/mousepad + /usr/bin/mousepad。运行时依赖系统 GTK3（libgtk-3-0 ≥ 3.16.2）、libgtksourceview-3.0-1、libglib2.0-0、libpango-1.0-0、libxfconf-0-3 和 gsettings 后端，均为 Ubuntu 20.04 仓库包。Launchpad 已发布 mousepad 0.4.2-1 in focal arm64（universe）。

发布说明：首发 KEMI Linux arm64：官方 Ubuntu 20.04 mousepad_0.4.2-1_arm64.deb 重打包为 kemi-mousepad；探针 requiredGlibc 2.17（1 ELF）。合主线：gork.bot协助开发
