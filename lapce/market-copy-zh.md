# Lapce

短描述：Lapce 闪电般的 Rust 代码编辑器（arm64）

长描述：Lapce 0.4.6 — 用 Rust 编写的闪电级代码编辑器（Floem / wgpu）。官方 debian bullseye arm64 deb 重打包；探针 requiredGlibc 2.30（1 ELF），适配 Ubuntu 20.04 / KEMI 101。布局 /opt/lapce + /usr/bin/lapce。运行时依赖 libssl1.1。

发布说明：首发 KEMI Linux arm64：官方 lapce.debian.bullseye.arm64.deb v0.4.6 重打包为 kemi-lapce；探针 requiredGlibc 2.30（1 ELF）。合主线：gork.bot协助开发
