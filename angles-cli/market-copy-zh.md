# Angles（商场文案）

短：Angles 开源终端 AI 编程 Agent（Linux arm64 静态）。上游 v0.6.3 单二进制重打包。gork.bot协助开发。

长：Angles Code CLI（angleschina）是 MIT 许可的终端原生 agentic coding 助手：单静态 Rust 二进制、30+ 内置工具、多模型 Provider。本包为官方 Linux arm64 发行物 v0.6.3 的 KEMI 重打包（静态二进制未改），适用于 Ubuntu 20.04 aarch64（KEMI 101）。无需 Docker / Node / Python。需用户自备 LLM Provider Key。合主线：gork.bot协助开发。安装后提供 `/usr/bin/angles`。
