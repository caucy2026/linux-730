# hrdr（商场文案）

短：hrdr（Herder）开源终端 AI 编程 Agent（Linux arm64 musl）。上游 v0.18.0 静态二进制重打包。gork.bot协助开发。

长：hrdr（Herder / kryptic-sh）是面向 OpenAI 兼容接口的开源 agentic coding harness：TUI、原生工具调用、会话与子代理。本包为官方 Linux aarch64 musl 发行物 v0.18.0 的 KEMI 重打包（静态二进制未改），适用于 Ubuntu 20.04 aarch64（KEMI 101）。无需 Docker。需用户自备 LLM Provider Key。合主线：gork.bot协助开发。安装后提供 `/usr/bin/hrdr`。
